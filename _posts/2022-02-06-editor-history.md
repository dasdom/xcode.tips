1. Navigate to different files in your projects... 
2. ... for example by clicking files in the Project navigator.
3. Use the shortcut control command left-arrow to navigate...
4. ... to the previously opened file in your navigation history. It's kind of like going back in the web browser.
5. After you moved like that back in your navigation history, you can use the shortcut control command right-arror...
6. ... to navigate forward in the navigation history.
